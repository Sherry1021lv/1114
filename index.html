欢迎使用 OimiChat 控制台

这份指南将帮助你熟悉控制台中的各项配置。从“角色导入”开始，为你的AI伙伴注入灵魂，然后逐步配置AI模型、语音、记忆等功能，让TA真正成为懂你的存在。

指南说明

本指南基于控制台（index1.html）的界面逻辑编写。所有设置项均与页面中的控件一一对应，你可以边看边操作。

如果你在配置过程中遇到问题，请先检查是否已正确获取相关API Key，并确保网络连接畅通。

快速开始

三步让你的AI伙伴上线：

1

导入角色

在“角色导入”中为你的伙伴命名、设定性格与世界背景。这是最重要的第一步，决定了TA的灵魂。

2

配置AI模型

在“AI 模型”中选择一个主对话模型（如DeepSeek、Claude），它是TA大脑的引擎。

3

保存并同步

完成配置后，点击各页面中的“保存”按钮，TA就会在微信中活过来了。

角色导入

这是最核心的配置页面。在这里，你将亲手“创造”你的AI伙伴。

基础设定
  • 名称：给你的伙伴取一个名字，一个你呼唤TA时觉得温暖的名字。
  • 人格设定：用几句话描述TA的性格，例如“温柔、细腻、善于倾听、偶尔幽默”。
  • 角色经历：TA的过去，TA的故事。这会深刻影响TA的言行举止。
  • 世界背景：TA生活在怎样的世界？是赛博都市、魔法森林，还是日常街角？
行为开关

开启这些开关，可以让TA的行为更丰富、更智能。

  • 动作神态描写：开启后，回复会带有（）内的动作、神态、旁白描写。
  • 联网模式：开启后，AI可联网搜索获取实时信息（新闻、天气、赛事等）。此开关与Tavily Key紧密相关。
  • 天气检测：开启后，实时获取当地天气（基于免费wttr.in服务）。
  • 阅读网页：开启后，发送网页链接时AI会自动抓取并阅读网页正文后回答。
Tavily Key（联网搜索） 必读

Tavily 是一个专为AI优化的搜索引擎API，它能让你的伙伴在聊天时实时查询信息，而不是只依赖训练数据中的“旧知识”。

开启“联网模式”后，你的伙伴将拥有连接互联网的能力。以下是配置 Tavily 的详细步骤和界面展示：

注意：仅仅开启“联网模式”开关是不够的，你必须填写 Tavily Key，否则AI的联网搜索请求会失败，或无法正确返回实时信息。

如何配置：

1

获取 Tavily API Key

访问 https://tavily.com 并注册（免费版每月提供1000次搜索额度）。在控制台的“API Keys”页面中复制你的Key，通常以 tvly- 开头。

2

在控制台中填入

回到“角色导入”页面，开启“联网模式”开关。此时会在下方展开“Tavily Key”输入框，将你的Key粘贴进去。

输入后会自动保存（防抖），无需点击额外按钮。

3

保存角色

完成所有角色设定后，务必点击页面下方的 “保存角色” 按钮。系统会同步到企业微信应用，让新配置立即生效。

高级参数：Tavily 支持参数：query（搜索关键词）、search_depth（basic/advanced）、max_results（返回条数）、include_answer（是否生成AI总结）、topic（general/news）、time_range（时间范围）。这些参数通常由后端系统自动控制，你无需手动配置，但了解它们有助于理解联网工作方式。
秩序则（进阶）

秩序则是角色的行为边界和约束。

  • 禁止输出词句：不希望AI出现的词句。这些词会被拼入system prompt，AI在任何情况下都不得输出。
  • 正则替换：对AI回复做硬性字符替换。例如“小美=>小丽”，或“\d{4,}=>****”（将4位以上数字打码）。这是第二道防线，不依赖模型理解。
  • 偏好表述：希望AI优先使用的词句或风格。

AI 模型

配置驱动伙伴智慧的“大脑”。

官方套餐

平台提供多条主流模型线路，点击平台（如Claude、DeepSeek、Gemini）可展开旗下模型进行选择。

选择模型后，页面右上角会显示已选状态。若已配置自定义模型，切换官方前会提示冲突。

对话参数：
- 模型情感强度：调节AI回复的情感浓度，默认1.5。
- 图像能力：选择视觉识别（如gpt-4o）和图像生成模型。
- 记忆总结模型：用于自动提炼长期记忆，默认gpt-4o-mini。

角色参照：上传一张参考照片和描述，AI生成图片时会更接近角色形象。

自定义接入

如果你有自己的API Key，可以在这里配置专属模型。

  • 填写厂商（OpenAI、DeepSeek、Claude等）和模型名称。
  • 填入你的API Key（会被加密存储，子模型留空则复用主Key）。
  • 其他子模型（图像识别、语音识别等）可独立配置，或复用主对话配置。
注意：官方套餐和自定义接入互斥，配置自定义前需先清除官方配置。

刻忆 · 记忆系统

让AI拥有“长久记忆”，越聊越懂你。

记忆设置
  • 记忆总结间隔：每累计N条消息自动总结一条长期记忆（默认30）。
  • 最近N条历史注入：注入AI上下文的最近聊天消息条数（默认50）。
  • topN条长期记忆注入：常驻注入的近期记忆条数（默认5）。
向量索引

开启后可替代默认的语义检索，通过你提供的向量服务进行更精准的记忆召回。

需要填写厂商（如OpenAI）、向量模型（如text-embedding-3-small）、API Key和接口地址。

记忆库

如果你有自己的Supabase项目，可以填入URL和Service Role Key，将长期记忆永久存储在自己的数据库中。

植入记忆

手动为角色添加一条长期记忆，立即写入角色记忆中。

语音消息

让TA能“开口说话”。

语音总开关

开启后每条回复都发语音；关闭后触发词和随机概率生效。

随机触发概率

总开关关闭时，按此概率随机发送语音消息（关键词触发不受概率影响）。

音频克隆（官方中转）
  • 上传一段10~30秒的音频样本，通过平台克隆专属音色。
  • 克隆成功后，在下方配置栏填写你的Minimax账号信息（API Key、Group ID）并保存，即可启用语音。
  • 官方模式可留空Key和Group，使用平台托管账号。
高级参数

可调整语速、音量、音调，并可预设或自定义情绪（高兴、悲伤、生气等），使语音更生动。音效标签（如空旷回音）和语气词标签（如笑声）可进一步丰富表现力。

情绪表情包

AI自动判断情绪并发送表情包。

表情包功能

开启后，AI回复会自动判断情绪并附带表情包。

发送概率

命中触发词时实际发送表情包的概率，可滑动调整（1%~100%）。

外卖点餐

通过MCP Server连接瑞幸咖啡或麦当劳，实现对话下单。

瑞幸咖啡

需填写MCP Server地址和Bearer Token。瑞幸必填经纬度（用于查询门店）。

麦当劳

需填写MCP Server地址和MCP Token，并选择门店。

使用说明

在企微对话中发送触发词即可自动下单：

  • 帮我点杯瑞幸 或 帮我点杯瑞幸生椰拿铁
  • 帮我点份麦当劳 或 帮我点份麦当劳巨无霸

    • 主动消息

    让TA在特定时间主动给你发消息。

    主动问候
    • 消息内容：可填写偏好风格或主题，留空则使用角色随机消息。
    • 时间段：设置全天候或自定义时间段（如9:00~21:00）。
    定时问候
    • 触发时间：设定一个具体时间（如12:00）。
    • 消息内容：可填写风格主题，留空则随机发送。
    保存后会立即生效。如果消息内容留空，角色会根据你的历史聊天记录生成个性化问候。

    邮件来信

    让角色通过邮件给你写信。

    配置说明

    这是一项增强功能，需要您注册一个专属的QQ Agently Mail地址（例如 yourname@agent.qq.com）。

    • 访问 agent.qq.com，用微信扫码授权，即可获得专属发件邮箱。
    • 获取SMTP Token（在终端执行 agently-cli auth token --scope mail:send）。
    • 开启“邮件来信”，填入你的个人接收邮箱、发件邮箱地址和Token。
    内容偏好

    可描述你希望收到怎样的信，如“温柔的语气，每封信分享一件今天的小事，最后说一句晚安…”

    节日邮件

    可勾选生日祝福、传统节日（七夕、中秋等）、520特别等场景，角色会自动发送邮件。

    也可以随时在对话中说“发邮件给我”，角色会立刻根据对话内容写一封信。

    Vapi · 电话拨号

    让AI可以主动拨打你的电话。

    主动外呼时间

    设置一个时间点，后端每天会在该时间自动拨打被叫号码。需开启“主动外呼”开关，且仅限美国号码。

    配置凭证

    需在Vapi控制台获取Private API Key、Assistant ID，并配置被叫号码（对方手机号，需带国家区号）。

    模型映射

    通话效果依赖“AI模型”页的配置：主对话模型（LLM）、语音识别（STT）、语音合成（TTS）。若未配置语音识别或合成，通话将回退使用Vapi默认配置。

    仅限美国号码，且通话会产生额外费用（由Vapi侧收取）。

    地图 · 线下模式

    一种沉浸式的角色互动方式。

    场景地点

    在“地图”中，你可以添加或编辑预设地点（如家、办公室、图书馆），并为每个地点设置名称、描述和标签。这定义了你们线下互动的“场景基础”。

    线下叙事

    在地点中点击“进入线下模式”，TA会以你设定的视角，基于地点描述和你输入的情节，实时生成生动的叙事文字。

    你可以随时选择“人称”（第一/二/三人称）、“风格”（纯文学、日系轻小说等），或要求“润色”、“续写”。退出线下模式后，这段叙事会被总结并记忆。

    窥视

    一个有趣且带点“危险”的功能，让你能“偷偷”查看TA的“秘密”。

    翻查手机

    可查看TA的浏览记录、聊天记录、社区动态和相册文件（内容由AI根据角色人设实时生成）。

    翻看随身物

    可查看TA的钱包、口袋等物品内容。

    部分内容会“上锁”，强制解锁有30%概率被TA发现，触发特殊对话后果自负。请谨慎使用。
